# 잔향 확장 설계안

정식판의 재플레이 가치를 만드는 축을 **분량이 아니라 잔향**으로 잡는다.
설정집을 늘리는 건 이미 24장면·2만 자인 게임에 읽을 거리를 더하는 것뿐이다.
잔향은 **같은 장면을 다르게 읽히게** 만들고, 그게 이 게임이 다른 텍스트 어드벤처와
실제로 다른 유일한 지점이다.

---

## 1. 지금 상태

| 항목 | 수 |
|---|---|
| 장면 | 24 (공통 Act1 6 · 루트별 5×3 · 공통 Act3 3) |
| 잔향 | **3** |
| 잔향 사용처 | **6** (24장면 중 6곳 = 25%) |
| 결말 | 6 |

```
PROLOGUE_RAIN → PROLOGUE_CHOICE → REN_GARAGE_01 → REN_GARAGE_02 → DECRYPT_01 → SKY_GLITCH_01
                                                                                    │ 3갈래 분기
     ├─ Ren  : AUCTION_01 → BACKROOM_01 → [LEDGER_01] → AUCTION_02 → SPLIT_01
     ├─ Kael : INTERROGATION_01 → HOLDING_01 → [ARCHIVE_01] → INTERROGATION_02 → ORDER_01
     └─ Echo : BROADCAST_01 → MARTYR_01 → [SIGNAL_01] → COUNT_01 → BROADCAST_02
                                                                                    │
                         CORE_APPROACH_01 → VIGIL_01 → DESIGNER_CONFRONT_01 → ENDING_*
```
`[  ]` = 현재 잔향이 나오는 장면. 루트마다 **3번째 장면 하나뿐**이다.

## 2. 문제

1. **루트의 절정이 아무것도 남기지 않는다.** 각 루트의 4·5번째 장면(`SPLIT_01`,
   `ORDER_01`, `COUNT_01`, `BROADCAST_02`)은 그 루트에서 가장 무거운 장면인데 잔향이 없다.
2. **결말이 아무것도 남기지 않는다.** 진엔딩에서 제인의 정체를 알아내도 다음 판은 모른다.
   가장 큰 진실이 가장 적게 남는다.
3. **분기점에 잔향이 없다.** `ACT1_SKY_GLITCH_01`은 세 루트를 고르는 자리다.
   지난 판의 기억이 가장 쓸모 있어야 할 곳인데 비어 있다.
4. **조합이 없다.** 셋을 다 알아도 선택지 세 개가 따로 뜰 뿐, "다 안다"는 상태가 없다.

## 3. 설계: 9개 잔향 · 3계층

| 계층 | 수 | 획득 방식 | 성격 |
|---|---|---|---|
| **루트 잔향** | 6 (기존 3 + 신규 3) | 장면 진입 | 각 루트가 2개씩 — 중반 1 · 절정 1 |
| **분기 잔향** | 1 (신규) | 장면 진입 | 반전 장면(`DESIGNER_CONFRONT_01`) |
| **결말 잔향** | 2 (신규) | 결말 도달 | 진엔딩 · 히든엔딩에서만 |

### 신규 잔향 6개

| id | 획득처 | label | 내용 (장면에 이미 있는 사실) |
|---|---|---|---|
| `name` | `ACT2_REN_SPLIT_01` | 분할기 앞의 4분 | 렌은 **이름이 붙은 것에 값을 못 매긴다.** 그래서 모든 걸 번호로 부른다. |
| `order` | `ACT2_KAEL_ORDER_01` | 복창하지 않은 3초 | 카엘의 명령서는 **전부 41층에서** 내려왔다. 그리고 그는 한 번 복창하지 않았다 — 규정상 침묵은 불복이다. |
| `mose` | `ACT2_ECHO_COUNT_01` | 모스의 어머니 | 동기화가 끊기면 **요양 구역 사람들이 가족을 못 알아본다.** 에코의 가장 어린 해커가 그걸 알고 걸어 나갔다. |
| `rien` | `ACT3_DESIGNER_CONFRONT_01` | 수조 속의 리엔 | 20년 전 도시를 살렸다는 리엔은 **죽지 않았다.** 잠들지도 못한 채 배양액 안에 있다. |
| `origin` | `ENDING_JAYNE_ORIGIN` | 섹터 9의 수석 연구원 | 제인의 3년은 분실이 아니다. **그녀가 스스로 지웠고**, 리엔이 "살리려고" 거들었다. |
| `cradle` | `ENDING_NEXUS_TRUST` | 내려앉은 장벽 | 리엔은 **스스로 꺼질 수 있다.** 통제를 내려놓는 선택지가 처음부터 있었다. |

> **원칙**: 잔향의 내용은 **그 장면에 이미 쓰여 있는 사실**이어야 한다. 새 설정을 만들지 않는다.
> 위 6개는 전부 현재 본문에서 그대로 끌어왔다.

### `mose`가 특히 좋은 이유

에코 루트에서 얻지만 **에코에게 불리하게 쓸 수 있는** 유일한 잔향이다.
카엘에게 넘기면 진압의 명분이 되고, 에코에게 들이밀면 그녀가 처음으로 자기 계획을 의심한다.
"지난 판에서 얻은 것이 이번 판에서 무기가 된다"를 가장 선명하게 보여주는 사례다.

## 5. 조합 잔향 (`requires` 배열)

`requires`를 **문자열에서 배열로 확장**한다. 두 개 이상을 들고 있을 때만 뜨는 선택지.

| 사용처 | 조건 | 무엇이 열리나 |
|---|---|---|
| `ACT1_SKY_GLITCH_01` | `ledger` + `signature` | 렌이 쪼갠 기억을 **41층이 산다**. 분기 전에 이미 두 세력이 한 장부 위에 있다는 걸 안다. |
| `ACT3_DESIGNER_CONFRONT_01` | `rien` + `origin` | 리엔을 **이름으로 부른다.** 그가 제인을 알아보는 유일한 경로. |
| `ACT3_VIGIL_01` | 루트 잔향 6개 전부 | 세 동행의 진실을 전부 아는 상태 — 마지막 문 앞 독백이 달라진다. |

이 세 개가 "다 모으면 달라진다"를 만든다. 수집 UI는 이미 있다
([EndingScreen.jsx:223](src/components/EndingScreen.jsx:223)에서 `n/total`을 표시하고 모르는 건 가린다).

## 7. 체험판 분모 — ✅ 결정·구현 완료 (2026-10-09)

**이게 이번 설계에서 가장 위험한 지점이었다.**

[EndingScreen.jsx:237](src/components/EndingScreen.jsx:237)은 체험판에서
`RESIDUE_COUNT - residue.length`개를 "정식판에서 열린다"고 표시한다.
잔향을 3 → 9로 늘리면 **체험판의 잠긴 개수가 2에서 8로 뛴다.**

체험판 플레이어가 받은 피드백이 정확히 *"I kept getting blocked by full version coming soon"*이었다.
분모를 그대로 키우면 같은 불만을 다시 만든다.

**해결**: 체험판은 **출처 장면이 체험판에 열려 있는 잔향만 분모로** 센다.
목록을 하드코딩하지 않고 규칙으로 유도하므로, 잔향을 추가해도 분모가 알아서 맞는다.

```js
// residue.js
export function residueAvailable(id, demo = IS_DEMO) {
  const from = RESIDUES[id]?.from
  if (!from) return false
  if (!demo) return true
  return !isLockedNode(from, demo) && !isWithheldGap(from, demo)
}
```

| | 지금 | 9개로 늘린 뒤 |
|---|---|---|
| 정식판 | 3 (`ledger`·`signature`·`cutpoints`) | 9 |
| 체험판 | **1** (`ledger`) | **2** (`ledger`·`name`) |
| 업셀 문구의 수 | 2 | 7 |

실제 화면 확인(체험판 빌드로 한 판 완주):

```
잔향 1/1
◈ 렌의 장부
남은 잔향 2개는 정식판의 카엘·에코의 길에 있다 →
```

정식판은 종전대로 `잔향 1/3`에 못 본 것 둘이 가려진 채 남는다.

**함께 한 것**
- `requires` **배열 지원**(`requiresOf`) — 5절 조합 잔향의 전제. 데이터는 아직 없다.
- **획득 가드** — 체험판은 반전 장면(`ACT3_DESIGNER_CONFRONT_01`)을 지나가므로,
  막지 않으면 잠가 둔 진실이 잔향 **이름으로** 새어 나간다. `mergeResidue`가 막는다.
  이미 가진 것은 지우지 않는다(정식판을 하던 브라우저를 존중한다).
- 업셀 문구의 "잔향 2종"을 하드코딩에서 `residueLockedCount()`로 바꿨다.
- 테스트 6개 추가. `npm test` 427개 통과, `npm run validate` 통과, 양쪽 빌드 통과.

### 2단계에서 드러난 것 — 분기·결말 노드의 `fixedChoices`

설계안은 분기점(`ACT1_SKY_GLITCH_01`)을 가장 중요한 사용처로 꼽았는데, 넣고 보니
**화면에 뜨지 않았다.** [App.jsx](src/App.jsx)가 분기·결말 노드에서는 `fixedChoices`
(강제된 루트/결말 선택지)로 **갈아치우고** 잔향을 버리고 있었다(`fixedChoices || [...]`).
원래 주석에도 "분기·결말 노드 제외"라고 의도적으로 적혀 있었다.

바꿨다 — 이제 `fixedChoices` **뒤에 이어 붙인다**. 잔향은 씬을 진전시키지 않으므로
강제된 분기 선택지는 그대로 남고, 플레이어는 고르기 전에 상대를 한 번 찔러볼 수 있다.
실제 화면 확인:

```
### 분기점 ACT1_SKY_GLITCH_01 (5개)
  0: [거래] 렌에게 값을 매기게 한다.
  1: [자수] 카엘에게 이 영상을 넘긴다.
  2: [폭로] 에코의 주파수를 연다.
  3: [잔향] 경비대 회선에 "사십일"이라고만 말한다.
  4: [잔향] 해적 주파수에 요양 구역은 어떻게 되냐고 묻는다.
```

`order_sky`를 쓰면 카엘 쪽 회선이 침묵하고, 세 갈래 분기는 그대로 남는다.
**5절의 결말 노드 조합 잔향도 이 변경 덕분에 가능해졌다** — 그게 없었으면 설계가 막혔다.
