## 어떤 게임인가

정화된 지구, 거대한 돔 안에 갇힌 인류. 플레이어는 기억 브로커 **제인**이 되어
도시의 진실이 담긴 칩 #00을 두고 세 세력 사이에서 선택한다.

- **렌** — 칩을 팔아넘기려는 암시장 브로커
- **카엘** — 칩을 회수하려는 보안국 수사관
- **에코** — 칩으로 도시를 깨우려는 방송 해커

플레이어는 선택지 3개 중 하나를 고르거나, **직접 문장을 입력**할 수 있다.
관계 게이지, 매 턴 올라가는 NEXUS 추적 시계, 증거 추리가 합쳐져 **6가지 엔딩**으로 갈린다.

## 만들면서 한 것들

### 1. 자체 모델 학습

API 비용 없이 오프라인으로 돌리고 싶어서 모델을 직접 학습시켰다.

- Claude를 교사로 삼아 학습 데이터를 만들고 (증류)
- Qwen2.5-7B를 QLoRA로 파인튜닝해서
- 맥에서 Ollama로 돌린다

처음엔 Colab에서 학습했지만, 나중엔 맥(M5)에서 MLX로 직접 학습하는 방식으로 옮겼다.
버전별 결과는 다음과 같다.

| 버전 | 결과 | 원인 |
|---|---|---|
| v3 | **91.8%** (채택) | — |
| v4 | 90.4% | 에폭을 줄여서 덜 배움 |
| v5 | 57.5% | 반대로 너무 많이 배움 (인사말에도 게임 JSON만 뱉음) |

한 번 고치면 반대쪽으로 넘어간다. 학습은 **두 방향 사이에서 적당한 지점을 찾는 일**이었다.

### 2. 그런데 재미가 없었다 → 서사를 직접 썼다

모델이 JSON 형식은 91.8%나 지켰는데, 막상 플레이해보니 **문장이 읽히지 않았다.**
형식은 맞는데 내용이 없었다. (자세한 내용은 1편에 정리했다.)

그래서 본편 장면을 **전부 손으로 썼다.** 장면마다 도입부, 선택지 3개,
그리고 **선택마다 다른 반응**을 쓴다. 지금은 24개 장면, 약 2만 자다.
어떤 선택을 하든 글이 달라지니 "선택이 무의미하다"는 문제도 같이 풀렸다.

### 3. 모델은 "판단"을 맡는다

직접 쓴 문장은 미리 준비해둘 수 없다. 여기서 모델이 쓰인다.

- 플레이어가 입력한 행동이 **어떤 선택지와 같은 의도인지** 분류한다 → 10/10
- 질문이면 **무엇에 대해 묻는지** 20개 주제 중에서 고른다 → 직접 쓴 답변 80개 중 하나를 보여준다
- 준비된 주제 밖의 질문이면 모델이 직접 답해본다. 단, **품질 검사를 통과한 답만** 화면에 나간다

모델이 잘하는 일(분류)과 못하는 일(글쓰기)을 **측정으로 나눈 것**이
이 프로젝트에서 가장 중요한 결정이었다.

### 4. 게임을 게임답게

- **세 인물을 먼저 보여주기**: 원래는 얼굴도 모르는 세력을 골라야 했다. 분기 직전에 셋 다 등장하게 바꿨다
- **고르지 않은 세력도 끼어들기**: 루트 중반에 다른 세력이 개입해서 게이지를 흔든다
- **엔딩 도달성 검증**: 엔딩 3개가 실제로는 도달 불가능했다. 루트 기반으로 조건을 다시 짰다
- **연출**: 나레이션 타이핑 효과, 클릭하면 전체 보기, 선택 후 0.5초 쉼
- **자동 플레이테스트**: 5가지 전략으로 끝까지 플레이하는 스크립트. 한 판에 9분 걸리던 게 90초로 줄었다

### 5. 모델 없이도 끝까지 플레이된다

본편이 전부 직접 쓴 글이라서 Ollama도 API 키도 없이 처음부터 엔딩까지 플레이할 수 있다.
모델이 있으면 자유 입력을 더 잘 알아듣는다.

```bash
npm install
ollama serve   # 별도 터미널
npm start      # Ollama → 모델 → 실제 추론 1회를 점검한 뒤 실행
```

## 돌아보며

**잘한 것** — 감으로 판단하지 않고 매번 쟀다. "문장이 길어서 안 읽힌다"는 가설은
재보니 이미 59자여서 틀렸고, 재지 않았으면 쓸데없는 걸 고칠 뻔했다.

**아쉬운 것** — 모델이 준비된 주제 밖 질문에 답하는 품질이 아직 3/8이다.
다음 재학습의 목표로 남겨뒀다. 배경음악도 아직 넣지 못했다.

**배운 것** — 지표가 좋다고 결과물이 좋은 건 아니다. 91.8%는 진짜 숫자였지만
"재미"와는 상관없었다. 그리고 AI 제품에서 할 일은 대부분 **모델 바깥**에 있다.
