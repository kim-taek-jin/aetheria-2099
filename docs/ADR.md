# ADR — 아키텍처 결정 기록 (Architecture Decision Records)

> 각 결정: **맥락 → 선택 → 근거 → 결과/트레이드오프**. 되돌아볼 판단의 로그.

---

## ADR-1. 자체 모델 번들 vs 클라우드 API (배포 모델)
- **맥락.** 상업 배포(스팀/텀블벅)에서 AI 비용 구조가 문제. BYOK는 플레이어에게 키를 요구하고,
  서버 호스팅은 1인당 과금이 누적된다.
- **선택.** **로컬 모델 번들** — 큰 교사 모델을 증류해 Qwen2.5-7B로 파인튜닝, 데스크톱 빌드에
  Ollama로 오프라인 구동.
- **근거.** 운영비 0 + 오프라인 + 프라이버시. 웹은 BYOK/데모로 남긴다(브라우저에서 7B 못 돌림).
- **결과.** 준수율 93.2%의 로컬 v3. 품질은 클라우드보다 낮지만 "플레이 가능"하며, 프리미엄
  품질이 필요하면 하이브리드로 클라우드 폴백(ADR-2).

## ADR-2. 하이브리드 프로바이더 라우팅
- **맥락.** 클라우드(고품질·유료)와 로컬(무료·오프라인) 각각 장단이 있고, 무료 클라우드는
  한도에 막힌다.
- **선택.** **우선순위 라우터**(`aiRouter.js`): BYOK 클라우드 > 로컬 자체모델 > 스크립트 데모.
  클라우드가 일시적으로 막히면 로컬로 **자동 폴백**. "내 모델 전용" 모드도 지원.
- **근거.** 상황에 맞춰 최선을 쓰되 플레이가 끊기지 않게. 순수 함수로 분리해 테스트 가능.
- **결과.** 키 유무·네트워크 상태와 무관하게 항상 진행 가능. 유닛 테스트로 폴백 경로 검증.

## ADR-3. Colab → 맥 로컬 MLX 학습
- **맥락.** 무료 Colab이 런타임 끊김·저장 실패로 학습을 두 번 유실.
- **선택.** Apple M5(24GB)에서 **MLX QLoRA** 로컬 학습(Unsloth는 CUDA 전용이라 배제).
- **근거.** 끊김·비용 0, 파일 로컬 보존, 반복 개발에 유리.
- **결과.** 재현 가능한 파이프라인. 대가: 24GB 통합메모리라 batch 2 + grad_checkpoint가
  안전선(느리지만 안 죽음), 대형 다운로드는 구간 재시도 다운로더로 우회.

## ADR-4. 단일 양자화 (fp16 원본 병합)
- **맥락.** 4bit 베이스에 학습→dequant→재양자화하는 이중 양자화가 준수율을 7점 깎았다.
- **선택.** LoRA 어댑터를 **fp16 원본에 병합** 후 q4_K_M **1회**만 양자화.
- **근거.** 병합 베이스의 품질이 최종 추론 품질을 좌우. 재학습 없이 재병합으로 해결 가능.
- **결과.** 81% → 88.6% 회복. 대가: fp16 원본(~15GB)을 받아야 함(병합 후 삭제 가능).

## ADR-5. 멀티턴 증류 데이터
- **맥락.** 단일턴 학습쌍만으론 모델이 "직전 대사와 다르게 말하는 법"을 못 배워 반복 발생.
- **선택.** 교사가 각 장면을 K턴 이어 플레이한 대화를 생성, 게임 루프 재생으로 **문맥 누적**
  학습쌍 구성.
- **근거.** 실패 모드가 "학습된 적 없는 능력"이면 데이터로 가르치는 게 근본 해결.
- **결과.** 축자 반복 소멸 + 준수율 상승. 대가: 데이터 생성에 서브에이전트 병렬 실행 필요
  (플랜 세션, API 크레딧 0).

## ADR-6. 결정론적 엔딩 게이트 + 데이터 기반 밸런싱
- **맥락.** 엔딩을 모델이 임의로 고르면 시스템(호감·추적·기억)이 의미를 잃는다.
- **선택.** `eligibleEndings`가 세이브 상태로 열리는 엔딩을 계산 → 모델은 그 안에서만 선택.
  밸런스 수치는 **자동 플레이테스트 로그**로 조정(직관 아님).
- **근거.** 플레이어의 판단이 실제로 결말을 가르게. 검증은 재현 가능한 하네스로.
- **결과.** 게이트가 실제로 강제되도록 `validBranch` 수정, 플레이테스트로 호감·추적 결함을
  발견해 튜닝(진행 중). 대가: 밸런스는 반복 검증이 필요(플레이테스트 ~75분/회).

## ADR-7. 저장 추상화 (웹 ↔ 데스크톱)
- **맥락.** 웹(LocalStorage)과 데스크톱(JSON 파일)이 세이브를 공유해야 이관 비용이 준다.
- **선택.** `SaveGameV1` + 순수 `serialize/deserialize`, `App.jsx`의 `storage` 객체만 교체.
- **근거.** 직렬화 형태를 버전드로 고정하면 Electron 이관 시 로직 무변경.
- **결과.** 데스크톱 포팅 비용 ≈ 0. 리로드 시 현재 씬 비트도 별도 저장해 복원.
