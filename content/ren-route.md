## 🔒 지켜야 할 설정(캐논) — 바꾸지 말 것
- 렌 = 섹터 0 정보상/메카닉. 냉정·실리. "정화된 외부 토지를 독점해 대기업에 팔자."
- 두 씬: **렌의 옥션(01) → 낙찰의 대가(02)** → Act3로 이어짐.

## 🎙️ 렌 캐릭터 참고 (이미 확정된 것)
- **말투**: 짧고 건조. 비유에 돈·부품·이자·거래를 섞음. 형용사 아끼고 감정 잘 안 드러냄.
- **대표 대사**: "공짜는 없어, 넌 뭘 담보로 걸 건데?" / "정보도 돈이야, 값을 치뤄야지." / "내가 전에 준 정보 값도 이자를 쳐서 받아야겠지?"
- **과거**: 섹터 0 빚 구덩이 출신. 어릴 적 행복한 기억이 빚 대신 팔려나감 → 모든 것에 값을 매기는 법을 배움.
- **비밀**: 팔지 못한 기억 칩 하나를 숨김 — 사랑했던 사람의 마지막 미소. 값을 매길 수 없는 유일한 것.
  (※ 카엘 루트의 '아렌 인식표'처럼, 이 비밀을 증거로 엮을 수 있음 — 원하면 활용)
